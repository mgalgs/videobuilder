# 3D shots

Use a 3D shot when camera movement, depth, or lighting conveys the idea better
than flat canvas shapes. Keep it to one storyboard segment. Time its motion and
hold from the content, snap the segment to the beat, then set the shot length
in frames to match it; see [storyboard.md](storyboard.md).

Write a `manimgx.ThreeDScene` in the film script's `build()` function. Use
`videobuilder.manimgx_shot.frames(Scene, SIZE, FRAMES, FPS)` as the source for
`videobuilder.shot3d.build('assets/name.mp4', source, SIZE, FPS, FRAMES)`.
`examples/shot3d_demo.py` is a complete example; build it with
`/opt/manimgx/bin/python examples/shot3d_demo.py --build`. The ManimGX venv
has system site packages, so it can import videobuilder. Remove default mesh
lines with `.set_stroke(width=0)` and `checkerboard_colors=False` on meshes.

Commit `assets/name.mp4` with the film. In `draw`, use
`clip = vb.Clip('assets/name.mp4')` and `cv.image(clip.frame(local_frame), ...)`.
Never commit a frame cache. If ManimGX reports no GPU adapter, stop and report
that condition; never try to leave the sandbox.
