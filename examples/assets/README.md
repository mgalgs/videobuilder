# Example assets

- `Cantarell-VF.otf`: Cantarell, variable font (wght 100–800), version 0.311,
  by The Cantarell Authors, from <https://gitlab.gnome.org/GNOME/cantarell-fonts>.
  Licensed under the SIL Open Font License 1.1: see `Cantarell-OFL.txt`.
  Used by `tour.py`.
- `Inter-Variable.ttf`: Inter, variable font (opsz 14–32, wght 100–900), by
  The Inter Project Authors, from <https://github.com/rsms/inter>. SIL Open
  Font License 1.1: see `Inter-OFL.txt`. Used by `benchmark.py`.
- `SourceCodeVF-Upright.otf`: Source Code Pro, variable font (wght 200–900;
  family name `SourceCodeVF`), by Adobe, with Reserved Font Name "Source",
  from <https://github.com/adobe-fonts/source-code-pro>. SIL Open Font
  License 1.1: see `SourceCodeVF-OFL.txt`. Used by `benchmark.py`.

- `orbit.mp4`: a 60-frame 3D shot rendered by this project with ManimGX
  (`/opt/manimgx/bin/python examples/shot3d_demo.py --build`). Project-original,
  under the repository's MIT licence. Used by `shot3d_demo.py`, the 3D
  capability demo and the showcase.

- `fox/`: one cartoon fox in six cut-out poses (`idle`, `point`,
  `surprised`, `cheer`, `talk`, `blink`), 1024x1024 RGBA PNGs. Generated
  with FLUX.2 [klein] 4B via WanGP, each pose made from `idle` as the
  reference image so the character stays the same; background removed with
  BiRefNet. Project-original, under the repository's MIT licence. `talk` and
  `blink` match `idle` except for the mouth and eyes, so they swap in place.

- `narration/`: generated voices, each a `.txt` script and the `.wav`,
  `.vtt` and `.json` that `python -m videobuilder say` made from it (the
  command is at the top of each script). Synthesized with Kokoro-82M
  (<https://huggingface.co/hexgrad/Kokoro-82M>, Apache-2.0) through
  kokoro-onnx's `kokoro-v1.0.int8.onnx`, voice `af_heart`. Generated for
  this project, under the repository's MIT licence. `fox` is the narration
  capability demo's line; `lumen` is the fox shot in `showcase.py`.

Everything else the example films show or play (the pictures, the JSON
backdrop, the click track and the music bed) is generated by code in the
films (`benchmark.py` uses the make-a-video skill's `make_track.py`).
